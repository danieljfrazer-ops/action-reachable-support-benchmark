# Interface spec v5 (frozen, one page) — basis for the independent black-box acceptance suite (contract E6)

Supersedes `interface-spec-v4.md`. Changes are the D-11 encodings only (contract v3.9): a secondary statistic accessor, per-instance fit keys, emission-timed alarm bookkeeping, and the pre-event support in the oracle labels. Everything else is v4 verbatim.

**Environment (agent-facing).**
- `reset(seed) -> (obs[C], info)`; `step(action[K]) -> (obs[C], info)`. Actions clipped to [−a_max, a_max]. `info` carries only `t` and `probe_flag`. Reward, terminated and truncated are **evaluator-side** fields in the ledger transition, not visible to the estimator unless its information set declares "reward visible".
- `probe(actions[steps, K]) -> list[Transition]`: applies the sequence; cost = `steps` probe steps against `probe_budget`; `probe_flag=True` on each.
- `Transition = (prev_obs, applied_action, obs, probe_flag, t)`; immutable; `t` counts environment steps from reset, so every arm's clock is the same clock (D-11.5). The evaluator's ledger transition additionally carries reward, terminated, truncated.

**Estimator.**
- **Construction and seeding.** The harness constructs one estimator object per (cell, instance_seed, episode_seed, confounder, arm): `Estimator(C, K, probe_rng_seed)` with `probe_rng_seed = [probe_ns, instance_seed, episode_seed, arm_id]` (integers; `probe_ns` and `arm_id` are fixed in the arm's spec; `instance_seed` is the certified sub-seed `Instance.seed`; the key excludes the confounder condition so present and absent share one probe allocation). Arms that draw no probes ignore it. The seed vector and the sha256 of the resulting probe allocation are ledger fields. Fitted artefacts survive across episodes only through `configure`'s bundle, never through object state.
- `configure(bundle)`: the **only privileged input**: `{regime_model_params | None, calibrator_params | None, arm_reference_params | None}` with hashes; the harness fits the isotonic calibrator (it owns the oracle labels) and injects it here; logged in the ledger.
- `fit_predictor(transitions)`: consumes the **instance's own** non-probed fault-free fit split (predictor-type arms; no-op for others). `fit_alarm_reference(transitions)`: consumes the **instance's own** arm-specific fault-free stream (probed for the probed arm) to set the alarm reference (k, ā, v). Two typed calls replace the single `calibrate` (R4-CX-05). `set_threshold(h)`: alarm threshold from the harness's ARL_0 calibration. **Fit hierarchy (D-11.6):** each of these is called once per (cell, instance_seed, arm) with data from that instance only; the harness records the key and the fit-split episode seeds; no artefact is reused across instances or across confounder arms.
- `update(transition) -> (raw_support[C], p[C] in [0,1], stat: float, raise: {0,1})`, once per environment step (a probe step is an environment step whose action was replaced); outputs may be piecewise constant between epochs (GM3-9). `raw_support` is the arm's **primary statistic**: the raw per-channel change-tracking statistic on which the evaluator computes the pre-event-support primary AUC (contract §G, D-11.1); higher = still controlled; returned every step (R4-CX-03). `raise = 1 iff stat > h` with **no persistence applied**. Declared `statistic_is_monotone_in_alarm=True`; declared `persistence_unit` (`steps` or `epochs`); declared `sign_blindness` = `formula` (R4-CX-10).
- `secondary_support() -> [C]`: the arm's **secondary full-channel statistic** (contract §G secondary outcome), read by the harness after each `update`; piecewise constant like `raw_support`; an arm without a distinct secondary returns `raw_support`. Never used for the primary.
- **Alarm bookkeeping (D-11.5):** the harness records each `update`'s `raise` with its `t` (for an epoch arm, one emission per epoch at the epoch step; for a step arm, every step) and applies persistence p in the arm's declared unit and refractory r in environment steps via `contract_ref.count_alarms_timed(raises, times, p, r)`; the fresh-start run length is `contract_ref.run_length_from_reset` and includes any warm-up prefix.
- `request_probe(steps) -> actions[steps, K] or None`.
- Declared `information_set` string; `needs_calibration_split` flag.

**Oracle (evaluator process only; never importable by the estimator).**
- `labels(t) -> {S_latent: bool[N_z], S_obs_eps: bool[C], S_obs_eps_pre: bool[C] (the support certified before the confirmatory event; the primary support set), confounded_mask: bool[C], e_interval: (lo, hi), R: float[N_b, 2K, |ℋ|] in probe order, M: float[N_b, K, |ℋ|] (family L only), zbar: float[N_z] (family N: empirical; family L: 0), P: (assign, gain, avail), events: list[(t, type, targets_changed)], s_change_certified: bool, n_lost: int}`.
- `score_support(t, offsets) -> F1 per offset` via snapshot-and-branch with common random numbers; asserted not to mutate live state, RNG, or estimator bytes (T-OOB).

**Metrics.** Existing in `contract_ref.py`: HPDT with frozen outcomes, `check_spacing`, `aggregate_primary`, `auc_prob_superiority` (secondary), `auc_pre_event_support` (primary), `count_alarms`, `count_alarms_timed`, `run_length_from_reset`, `match_alarms`. 0A deliverables (uncovered): ARL_0 calibration per the D-2a rule with the D-11.5 clock, Brier, log loss, F1 at offsets, `select_interaction_cells`, isotonic p_c calibrator.

**Ledger row.** code hash, config hash, lock hash, interpreter, environment, family, regime, confounder, distractor_level, delay, **instance_seed, episode_seed, fit-split episode seeds, probe_rng_seed, probe allocation sha256**, estimator, information_set, regime_bundle hash, spec file digest, threshold, persistence_unit, ARL_0 attained with interval and censoring fraction, probe steps used, policy_action_rms, probe_mag_over_action_rms, p_epoch_1_alarm_times, raw_support_stat_stream (the primary statistic per channel per emission; the primary AUC is computed on this, never on p_c), secondary_support_stream, operations, thermal pressure, outcome (complete, failed, NaN, not_in_band), metrics (R3-18).
