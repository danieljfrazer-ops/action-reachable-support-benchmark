# C1–C20 application check

Reviewed against `roadmap-v3.md` and `stage-0a-contract-draft.md` on 6 September 2026. “Resolves” means the substantive objection is addressed at roadmap level; it does not mean the implementation has already passed the proposed gate.

| ID | Status | Assessment |
|---|---|---|
| C1 | **Partially resolves** | V3 replaces one vague boundary with three targets, which is the right move. But the targets are not yet mutually coherent. `S_t` is defined over observation dimensions, while a sensor swap is said to change only `P_t` and leave `S_t` unchanged. A swap involving a controllable channel moves observation-space support. `M_t` is also underspecified for nonlinear/saturating dynamics, and `P_t` combines identity, permutation, gain and dropout. |
| C2 | **Partially resolves** | The five distractor classes and the shared-cause idea materially improve the design. The contract still lacks the structural equations and intervention coupling needed to establish that the action-correlated distractor is exogenous. Copied sensors and downstream consequences also need explicit scoring rules: they are causally action-responsive but not direct body channels. |
| C3 | **Resolves** | V3 presents Paper 1 as a standardised stress test at a surviving intersection, not as discovery of intervention-based boundary estimation itself. The proposed contribution is now the changing-boundary benchmark, metrics and failure map. |
| C4 | **Resolves** | Paper 2 no longer claims that predicting one’s own hidden state is new. It treats the auxiliary self-model as a tested adaptation aid and makes adaptation benefit, not mere predictability, the central question. |
| C5 | **Resolves** | The Paper 2 target is narrowed to future pre-update latent state with stop-gradient; prediction error and controllability mask are separated as ablations, and privileged versus learned targets are distinguished. |
| C6 | **Partially resolves** | Brier score and log loss are primary, ECE is secondary, and a calibrator is introduced. Missing pieces remain: the calibration split unit, treatment of temporal/within-episode dependence, raw-versus-calibrated reporting, target-specific calibration for `M_t` and `P_t`, and a predeclared binning convention for ECE. |
| C7 | **Resolves** | The “universal testbed in four weeks” has been decomposed into 0A, 0B, S, Paper 1 and Paper 2. The boundary testbed no longer depends on memory routing, compute allocation or Premakumar reproduction. The estimates are still optimistic, but that is now a timing problem rather than the original scope error. |
| C8 | **Misapplies it** | Positive-control failure is a valid stop, but the efficacy rule says to redirect if the confidence interval “excludes the smallest effect of interest” on both families. A CI wholly above the SOEI also excludes it and should mean success, not redirect. The rule therefore admits the opposite of the intended decision and also leaves one-family success/failure ambiguous. |
| C9 | **Partially resolves** | V3 correctly splits the Bayesian comparator into correctly specified, misspecified and detector-only variants and forbids calling the last two oracles. The likelihoods, priors, access to event families, online update rule and tuning budget are not yet frozen, so fairness is not yet auditable. |
| C10 | **Resolves** | Zero-cost probes, fixed probe schedules and learned cost-aware intervention policies are separated; task and intervention cost are to be reported on Pareto curves, and controller use must be declared. |
| C11 | **Partially resolves** | Alarm persistence, per-seed summaries and bootstrap intervals are mentioned. There is still no numerical persistence rule, per-target alarm semantics, reset/censoring convention, event-matching window, or definition of false alarms when changes occur close together. |
| C12 | **Partially resolves** | ABA/ABC counterbalancing and a morphology-library ablation are good additions. Reintroduction can still be confounded by unequal exposure, dwell time, transition count, retained optimizer/detector state and exact-instance recognition. An unseen but structurally matched `A'` condition is missing. |
| C13 | **Partially resolves** | V3 reduces Paper 1 to one primary contrast and labels the response surface exploratory. But it still chooses the primary contrast/operating point after inspecting a pilot “via simulation-based power analysis,” which can select the most favourable contrast. H3 also privileges the correctly specified Bayesian reference by construction and should not be confirmatory. |
| C14 | **Partially resolves** | The roadmap requires frozen, named baselines and equal tuning budgets. The Stage 0A contract still lists baseline families rather than executable specifications, reference implementations, parameter grids and numerical anchors. “Qualitative ordering” is too weak to validate a reproduction. |
| C15 | **Partially resolves** | Dates are now tied to named phases; venue eligibility must be checked live; arXiv is the first milestone and workshops are not treated as archival by default. However, the 0A/0B/S estimates omit review-and-repair cycles and the Paper 1 fractional design is not specified well enough to estimate runtime. |
| C16 | **Resolves** | Daniel’s D1 supplies a defensible compromise: the memory work remains the first public milestone as a bounded shakedown, contains no learned router, runs in parallel with 0B, and is cut if 0A slips beyond 22 September. |
| C17 | **Resolves** | The programme is modular rather than one universal environment: Stage 0A/0B is the causal-boundary testbed, Phase S is a separate symbolic memory shakedown, and later work has independent gates. Two dynamics families are required for Paper 1. |
| C18 | **Resolves** | The four-rung ladder has been replaced by orthogonal capability axes. “Self-awareness” is confined to one motivation sentence with an explicit non-claim; the scientific claims use measurable constructs. |
| C19 | **Resolves** | Premakumar is removed from Stage 0, retained only as a Paper 2 prerequisite, while IBD remains where it is directly relevant. Phase S has its own memory baselines rather than importing unrelated controls. |
| C20 | **Partially resolves** | V3 explicitly labels Tomaszewski et al. a preprint and requires live venue checks. It does not consistently label the status and date of every 2026 preprint in the related-work narrative, and Phase S’s “no prior paper reports this exact table” remains a search conclusion rather than a systematic-review result. |

## Bottom line

Nine findings are resolved at roadmap level, ten are partially resolved, and C8 is misapplied. The most consequential outstanding items are C1, C8, C11, C13 and C14. C1 must be repaired before implementation because it changes the ground-truth API and several supposedly executable invariants.
