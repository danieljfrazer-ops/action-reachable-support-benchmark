## 2. Attacks that failed

- **The H-horizon Jacobian recursion.** I tried to show `J^{(h)} = J^{(h−1)} β_o + β_{a,h−1}` is not `∂ô_{t+h,c}/∂a_{t,k}`. It is exact under the stated convention: expanding the fitted one-step map three times with `a_{t+1} = a_{t+2} = 0` reproduces the recursion term by term. §2 is algebraically correct, and the iterated-prediction convention correctly mirrors C2/C4.
- **Scale invariance of `l`.** I tried to break the claim that rescaling a channel leaves `λ`, the `l` vector and the `q` ranking unchanged. The similarity-transform argument holds: standardising the penalised columns makes `λ = λ_rel·n` unit-free, and the `γ` in `J^{(h)}_{:,c}` cancels against `σ_c`. R4-CX-02 is properly fixed.
- **The observation clock.** I tried to find an off-by-one between §2's index table and the generator. There is none: with the generator's delay queue (`queue.append(a); a_delayed = queue.pop(0)` on a list of `τ` zeros), a probe at `t_p` first moves `o_{t_p+τ+1}` at both τ = 0 and τ = 2, exactly as §2 and T-IBD-horizon state. The residual defect is the probe *count* (R5-23), not the clock.
- **Balanced-block state dependence.** I tried to show the allocation is adaptive or state-coupled. It is not: the draw depends only on the estimator RNG and the grant condition only on `t`. Group sizes in full windows are exactly [5, 7], as §3 derives.
- **The `σ_U²` tie correction.** Matches the standard tie-corrected Mann–Whitney variance; the `sqrt(max(0, ·))` guard and the 12-digit tie rounding are correct.
- **`draw_certified` returning an uncertified instance.** Mutant R5-M11 (accept the first draw regardless) is **killed** by `test_gen_perturbation_set_still_certifies`. The acceptance loop is sound; the defect is in what `certify` checks (R5-6).
- **Mutant "drop the ρ_cl conjunct".** I could not build an instance with `ρ_cl > 0.98` while the other four conjuncts hold — an out-of-band closed loop also saturates, so `sat` rejects it first. Reported as a failed attack rather than a survivor, because I cannot prove the mutant behaviourally distinct. It remains true that no gate test forces `ρ_cl`.
- **Mutant "apply the event after the action at `event_t`".** A genuine no-op in family L: the default policy `W_o o + W_u u + ε` never reads `B`, so moving `apply_event` one position inside the loop changes nothing. Informative rather than a defect — but it means the offset convention "the event applies before step `event_t`" is currently **unobservable** on this generator, and would become observable only for `sensor_dropout` / `sensor_gain`.
- **Degeneracy firing under perturbation.** I tried every point of the frozen perturbation set plus `N_x = 30` and `τ = 2`; `min σ_c` stays 20–40× above the threshold. Confirmed unreachable rather than mis-specified (folded into R5-15).
