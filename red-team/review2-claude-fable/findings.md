## 2. Attacks that failed (claims that held under my checks)

- **A1 Freeze hash.** Reproduced exactly (sha256, concatenation of the 9 files in the order listed in §0). The freeze claim is verifiable; only the file list is undocumented (FB-19).
- **A2 Gate exit code.** `run_gate.py` exits 0 with the documented interpreter and pinned numpy; the checked-in `gate.output.txt` matches my run byte-for-byte.
- **A3 C4 delay semantics.** The closed form `A_b^{h−1−τ} B` for h > τ and 0 for h ≤ τ is right; verified by an independent CRN simulation of the full noisy system, not through `test_gate`. Max error 4.8e-14.
- **A4 C1 reachability including downstream d.** Graph reachability agrees with the numeric Jacobian pattern on [b; d] for H = 1..7 at τ = 2, including "d first reached at h = τ + 2".
- **A5 Mutants the gate does catch** (`killed_mutants.py`): adjacency transposed (K4, C1 chain, K10 fail); reachability propagating one step too few; open-loop action held for τ+1 steps; signed gain instead of \|gain\| (L5 fails); HPDT scoring missed as 0. - **A6 CSV structure.** 1,764 rows; role, seed, level, delay, regime and confounder counts match `make_confirmation_design.py` and v4.1 E6 exactly (10 seeds primary and diagnostic, 3 seeds descriptive).
- **A7 `boundary-bench` collision (D13).** Live check 6 Sep 2026: PyPI has no such package (JSON and simple-index endpoints 404), but `boundarybench.com` is an active coding-agent benchmark ("Boundary-Bench"), so the decision to avoid the name is sound.
- **A8 IBD probe-phase claim.** arXiv 2603.18257 (v2, 7 May 2026) exists with the stated mechanism (randomised own actions, per-dimension two-sample tests with FDR, up to 100 distractors); the ≈ 32K-step default probing phase is consistent with the paper's own description.
- **A9 Pendulum-v1.** Continuous torque Box(−2, 2), no natural termination, 200-step truncation (gymnasium docs); the plan discloses replacing it with 1,000 steps. Consistent.
- **A10 Interaction estimand I (v4.1 E1)** is algebraically the right object for separating confounding from generic misspecification, and the intersection-union decision rule (both SCM families, both T2 signs) needs no multiplicity adjustment. What fails is not the algebra but the inputs (FB-7, FB-8, FB-11).
